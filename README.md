# app-gimnasio

Aplicación en Java para gestionar rutinas de gimnasio y calorías, creada con el objetivo de aprender y dar uso a lo visto en clase.

## Qué hace
- Crear una rutina por día (se guarda en un fichero)
- Consultar las rutinas guardadas
- Calcular de forma aproximada las calorías quemadas en el día, sumando el ejercicio del gimnasio y los pasos diarios

## Cómo ejecutarla
Abrir el proyecto en Eclipse y ejecutar la clase principal. Funciona con un menú por consola.

## Cambios a futuro
- Cambiar los ficheros por una base de datos
- Convertirla en una aplicación de escritorio
- Convertirla en una aplicación móvil
- Mejorar la interfaz
- Añadir más funciones para hacerla más práctica y útil
